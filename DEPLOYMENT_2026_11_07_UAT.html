  1. Take a database backup so that a rollback is exact.
  2. Unzip over the source tree of your UAT deployment, leaving out k8s as above.
  3. Delete backend/core/feed_timeout_sweeper.py if it is still there.
  4. Build these images and push them with the tag you deploy:

  5. Roll out the new images the way you did for the last update.

3 · One chart line, only if you use Embedding sites

The new Admin screen Embedding sites lets an admin change which sites may show an embedded report, with no deployment. The UI pod reads that list from the API. Add this to the UI chart's config values, using your API service's name and port inside the cluster:

internalApiUrl: "http://querystudio-api:8000"

Also add this line to ui/templates/configmap.yaml, above "frameAncestors":

"internalApiUrl": {{ .Values.config.internalApiUrl | default "http://querystudio-api:8000" | quote }},

Without it the UI pod tries your public API address instead. If it cannot reach that, the UI log says [frame-policy] could not read /api/embed-sites and the pod keeps the list it already has, so a change on the screen does not take effect. Reports and everything else still work.

4 · What is new

AreaWhat a person sees
Comment on the numberClick a table row or cell, a finance grid line, a bar or a slice, and choose Add a comment. A small marker stays on that number, even after sorting or paging.
Draft it for meDraft fills the comment box with a sentence built from the data, such as what moved and by how much. The person edits it and posts. Nothing posts by itself, and it works with no assistant set up.
Carry forwardThe box offers the note from the earlier run for the same number, and Use it posts a new comment marked as carried. It is never copied by itself and never crosses to another person's data scope.
In the exportsThe PDF has numbered markers and a Commentary section. Excel has a Commentary sheet and cell notes. Each export can be with or without commentary. Share and embed links leave it out.
Needs explainingFor each report you set a measure, a comparison and a limit. Movements over the limit with no comment are listed. At sign-off the person gets a warning, or is stopped if the report is set to Block. A warning overridden is recorded on the sign-off.
One panel, @mentions, resolveOne Commentary panel for this run and this report, with Open / Resolved, replies and Resolve. Type @ to tell someone; they get a notice with a link to the number. A person who may not see that data gets no note text.
Embedding sitesAdmin screen for which sites may show an embedded report, with no deployment.
Each embed linkA link can fix values on the server, so a page cannot change them, and has its own options: reader controls, whole report, downloads. One Embed dialog. A report may now have 100 links, up from 5, so each team can have its own.
Detail popups on an embedA click on an embed opens the rows behind it, inside what the link allows.

7 · Known and not in this update

  • The report framework and the simple builder are not in this zip. Their build starts today at 14:00 and will change the report screens. Expect the Sunday or final update to move things you test here.
  • Comments belong to a run. Refresh makes a new run with no notes on it. Carry forward offers the earlier notes.
  • A published API on Snowflake is still not fixed, because the cause is not known. I need the exact error text, the SQL, and whether it is a SQL API or a report API.
  • A shared file download on a table with row policies is refused, which is correct, but the message is poor.
  • A summed whole number in a CSV downloads as 1000.0.
  • A linked-tile filter does not narrow a popup's detail unless the action maps it. The popup says so.

8 · Check after deploying (20 minutes)

  1. Component Health is green.
  2. On a report, click a number, add a comment, and check that the marker stays after you sort the table.
  3. Press Draft on a report with a comparison and check the sentence against the numbers.
  4. Download the PDF and Excel and find the note in each.
  5. Set a limit under Needs explaining, then try to sign. You should get the warning.
  6. Mention a colleague with @. They get a notice, and its link opens the number.
  7. Add a test site on Admin, Embedding sites, and check that a page on that site can show the report.
  8. Press Run now on a feed. It completes, the file arrives, and its progress lines show.

9 · If you must roll back

Deploy the previous images, or use helm rollback if the deployment changed through Helm. The new columns can stay: older code does not read them, so the database needs no change. Comments and sign-offs written in the meantime stay in place.
