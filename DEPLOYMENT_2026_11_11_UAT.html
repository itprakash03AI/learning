4 · What to test (about 20 minutes)

  1. Share a Vault connection. Take a connection that logs in with a Vault System Account and was once saved with a typed password. Share it with another user or group: it is accepted. Open it: there is no typed password, only the Vault account. The other user runs a query on it.
  2. AWS Portal. Admin → AWS Portal: type your Service-First Reference Number, save, reload: the value is there. An S3 portal connection with no number of its own now reads its tables. Test still passes.
  3. System Accounts. Admin → System Accounts: the list fills the window. Open a Vault account with Edit: the Vault addresses you saved are shown, and the password is not. Use Test on that account.
  4. Wide lists. On a wide monitor, open Saved Queries, Schedules and Published APIs: each list fills the width.
